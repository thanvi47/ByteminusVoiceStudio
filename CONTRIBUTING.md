# Contributing

Welcome! Bengali pronunciation, accessibility, testing and local neural engine integrations are useful contributions.

1. Open an issue with a reproducible bug or proposed improvement.
2. Fork the repository and create a focused feature branch.
3. Install with `npm ci --legacy-peer-deps` (the lockfile is committed).
4. Keep paid services out of required runtime paths. Verify the license of any model and its weights separately.
5. Run `npm test`, `npm run typecheck` and `npm run build` before a pull request.
6. Describe user-visible behavior, validation and remaining limitations.

Do not contribute private scripts, credentials or voice samples without permission. Voice cloning requires explicit speaker consent. Keep interfaces honest about provider quality, accents and capabilities.
