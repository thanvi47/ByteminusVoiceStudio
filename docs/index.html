ByteminusVoiceStudio is a free, open-source text-to-speech application for turning Bangla and English scripts into neural voiceovers on your own computer.

Export WAV or MP3 audio and estimated SRT subtitles. Explore expressive delivery with local models. No paid speech API is required.

From script to voiceover and subtitles

Write in Bangla or English

Paste a script or import TXT. Choose a language and model voice, adjust manual speed and pitch, and add explicit pause tags.

Generate voice + SRT

Listen to the generated audio and download WAV/MP3 and SRT. Subtitle timing is estimated at sentence level; review it before publishing.

Keep inference local

Models run on your computer after installation. Packages and weights need an initial download. Optional Indic access requires your own Hugging Face approval.

Choose a speech engine for your language

Bengali · Mithi

10 Bengali model profiles for ordinary neural narration. Prompted emotional acting is not supported by this engine.

English · Kokoro

28 US/UK English profiles for neural voiceovers. Manual speed and pitch controls are available; prompted emotions are not.

Expressive · Parler

34 named English speakers and optional Bengali Indic Parler. Direction prompts guide calm, excited or scared delivery; exact acting varies.

Profiles are synthetic model speakers, not verified voice artists. Optional private cloning requires your own voice or the speaker’s consent and has separate model license restrictions.

Install on your own computer

Start with Node.js 22+ and Git. Allow storage for packages and model weights. Your computer, electricity and bandwidth remain your responsibility.

Windows x64

git clone https://github.com/thanvi47/ByteminusVoiceStudio.git
cd ByteminusVoiceStudio
./scripts/setup.ps1
npm run dev

Apple Silicon / Ubuntu Linux

git clone https://github.com/thanvi47/ByteminusVoiceStudio.git

Open http://127.0.0.1:3000 after setup. Keep the terminal running. Optional Bengali expressive, cloning and transcription models have additional installation steps.

CPU/GPU compatibility and update instructions: automatic CUDA, ROCm, Intel XPU and Apple MPS probing; experimental Windows DirectML. Unsupported GPU speech operations fall back to the same model on CPU in auto mode. Acceleration is not guaranteed for every GPU. Intel Mac native installation is unsupported by the pinned neural stack.

Questions about free Bengali and English TTS

Can I convert Bengali text to speech for free?

Yes. Install the studio and select a Mithi Bengali voice. Enter Bangla text and choose Generate voice + SRT. There is no paid TTS API requirement; inference uses your computer.

Does English speech support emotion and voice direction?

English Parler accepts descriptive delivery prompts. Optional Indic Parler provides Bengali expressive speech after its gated setup. Mithi and Kokoro do not perform prompted emotional acting. Review outputs because pronunciation and acting can vary.

Can I download MP3, WAV and subtitles?

Yes. Generated speech can be exported to WAV or MP3, with estimated sentence-level SRT. Exact word alignment is not included.

Does it work offline?

Initial installation downloads software and model files. Installed local speech models do not require a hosted inference API. Optional model access approval and downloads need internet.

Is it suitable for commercial voice cloning?

The app is GPL-3.0-or-later; main Mithi/Kokoro/Parler releases are Apache-2.0. Optional OmniVoice model weights have noncommercial/community terms, so do not assume unrestricted commercial cloning rights. Read the third-party notices.

বাংলা ভয়েস ও subtitle কীভাবে বানাব?

Install করার পরে studio-তে বাংলা ভাষা ও Mithi voice নির্বাচন করুন। Script লিখে Generate voice + SRT চাপুন, তারপর অডিও ও SRT download করুন। বাংলা emotion চাইলে আলাদা Indic Parler setup প্রয়োজন।
